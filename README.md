# B-Task
B-Task is a simple task manager. 
The current version [v1.4] is stable, future updates are possible.
For best performance, use with Windows 11.

## Instructions:
1. Download the .zip file with the latest version of B-Task
2. Unzip it
3. Launch B-Task.exe

Feel free to play around the code and make your own changes. Build with Qt.
